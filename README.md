# رواق — مدرسة الفقه والحديث

تطبيق ويب عربي لتعليم **الفقه الإسلامي وأصوله** و**الحديث النبوي وعلومه**، بتصميم هادئ فاخر وحركات سلسة، مع وضع ليلي ونهاري وتلقائي، ومُعين ذكي يعمل بـ Gemini.

## المزايا

- **جناحان منفصلان**، لكل منهما منهج متدرج واضح (أين أنت، وماذا بقي، والدرس التالي):
  - **الفقه وأصوله**: فقه العبادات المقارن (47 درساً) مستفاد من «المغني» لابن قدامة و«المجموع» للنووي و«بداية المجتهد»: الطهارة، والصلاة، والزكاة، والصيام، والحج — بأقوال المذاهب الأربعة وأدلتها؛ ثم أصول الفقه (11 درساً). ومتون للقراءة: الأخضري، وأبو شجاع، والورقات.
  - **الحديث وعلومه**: شرح المنظومة البيقونية بيتاً بيتاً (34 بيتاً في 26 درساً) مع تتمات من «نخبة الفكر»، ثم مدخل إلى السنة وشرح الأربعين النووية كاملة (42 حديثاً).
- **كل درس**: النص (بيت أو حديث أو آية)، والمفردات، والشرح في أقسام قابلة للطي، والأمثلة التطبيقية، والخلاصة، والتدريبات بأجوبتها، والاختبار.
- **تنزيل الدرس ومشاركته**: صورة PNG أو ملف PDF أو مشاركة مباشرة أو نسخ النص.
- **التحفيز**: نقاط، ورتب، وسلسلة أيام، وهدف يومي، وخريطة مداومة، وأوسمة.
- **خطط دراسية** لكل جناح، ووِرد اليوم في الرئيسية.
- **المُعين**: من أي درس أو مسألة: وسّع الشرح، بسّطه، أمثلة، قارن المذاهب، اختبرني؛ وصفحة محادثة كاملة.
- بحث فوري (Ctrl+K)، وأرقام غربية 123، ومظهر ليل/نهار/تلقائي، وتصميم خالٍ من نوافذ المتصفح المدمجة.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم ضع GEMINI_API_KEY
npm run dev
```

- `npm run build` — بناء الإنتاج
- `npm test` — الاختبارات
- `npm run typecheck`

## الذكاء الاصطناعي (Gemini المجاني)

- احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/apikey).
- الخادم: `api/ai.ts` (دالة Vercel)، ويستعمل المعالج نفسه خادمُ التطوير عبر Vite. المفتاح `GEMINI_API_KEY` يبقى في الخادم.
- النموذج الافتراضي: `gemini-3.8-flash` (متاح في الطبقة المجانية)، ويمكن تغييره بـ `GEMINI_MODEL`.
- عند انشغال النموذج ينتقل المُعين تلقائياً إلى نموذج مجاني آخر، وإن انقطعت الإجابة أكملها من حيث توقفت. ولا يظهر اسم المزوّد للمستخدم.
- تعليمات النظام في `src/shared/ai-core.ts`.

## النشر

جاهز للنشر على Vercel (`vercel.json` يوجّه المسارات إلى التطبيق، و`api/` للدوال). أضف `GEMINI_API_KEY` في متغيرات البيئة.

## البنية

```
src/data/         المحتوى العلمي: الأجنحة، المسارات، المتون، الخطط
src/lib/          التقدم والأوسمة (progress.ts)، الحالة (store.ts)، المُعين (ai.ts)
src/shared/       نواة المُعين المشتركة بين الخادم والمتصفح
src/pages/        الصفحات
src/components/   المكوّنات
api/ و server/    نقطة ‎/api/ai‎
```

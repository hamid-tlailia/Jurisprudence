# الرِّواق — مدرسة الفقه والحديث

تطبيق ويب عربي لتعليم **الفقه الإسلامي وأصوله** و**الحديث النبوي وعلومه**، بتصميم هادئ فاخر وحركات سلسة، مع وضع ليلي ونهاري وتلقائي، ومُعين ذكي يعمل بـ Claude.

## المزايا

- **أربعة مسارات** (٤٣ درساً): الفقه، أصول الفقه، الحديث النبوي، مصطلح الحديث — لكل درس أقسام وخلاصة واختبار.
- **المكتبة**: خمسة متون مشروحة مسألةً مسألة:
  الأربعون النووية، المنظومة البيقونية (كاملة)، الورقات للجويني، مختصر الأخضري (مالكي)، متن أبي شجاع (شافعي)، مع التنبيه على أقوال المذاهب.
- **التحفيز**: نقاط، ورتب، وسلسلة أيام، وهدف يومي، وخريطة مداومة، و١٧ وساماً.
- **خطط دراسية**: التأسيس الشامل (٣٠ يوماً)، طالب الحديث، المتفقه، خمس دقائق يومياً — وورد اليوم في الرئيسية.
- **المُعين (ذكاء اصطناعي)**: من أي درس أو مسألة: وسّع الشرح، بسّطه، أمثلة، قارن المذاهب، اختبرني؛ وصفحة محادثة كاملة بسجل محفوظ.
- بحث عربي يتجاهل التشكيل واختلاف الهمزات، وحفظ المسائل، والتحكم في حجم الخط.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم ضع ANTHROPIC_API_KEY
npm run dev
```

- `npm run build` — بناء الإنتاج
- `npm test` — الاختبارات
- `npm run typecheck`

## الذكاء الاصطناعي

- الخادم: `api/ai.ts` (دالة Vercel) ويستعمل المعالج نفسه في خادم التطوير عبر Vite. المفتاح `ANTHROPIC_API_KEY` يبقى في الخادم.
- النموذج: `claude-opus-5-5` مع بث متدفق، وتفعيل الانتقال التلقائي إلى نموذج بديل عند رفض المصنِّفات (`fallbacks: "default"`).
- بديل: يمكن للمستخدم إدخال مفتاحه الخاص من الإعدادات فيُستدعى Claude من المتصفح مباشرة (مفيد عند النشر كموقع ثابت).
- تعليمات النظام في `src/shared/ai-core.ts`: عربية فصحى، نسبة الأقوال إلى المذاهب، عدم اختراع الأحاديث، والإحالة إلى أهل العلم في النوازل.

## النشر

جاهز للنشر على Vercel (`vercel.json` يوجّه المسارات إلى التطبيق، و`api/` للدوال). أضف `ANTHROPIC_API_KEY` في متغيرات البيئة.

## البنية

```
src/data/         المحتوى العلمي: المسارات، المتون، الخطط
src/lib/          التقدم والأوسمة (progress.ts)، الحالة (store.ts)، المُعين (ai.ts)
src/shared/       نواة المُعين المشتركة بين الخادم والمتصفح
src/pages/        الصفحات
src/components/   المكوّنات
api/ و server/    نقطة ‎/api/ai‎
```
